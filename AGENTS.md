## 1. RÈGLES GÉNÉRALES
- Ne jamais modifier un article existant sans demande explicite
- Ne jamais supprimer du contenu existant
- Tous les nouveaux articles doivent suivre une structure uniforme
- Le site doit être optimisé SEO (Google-first)
- Le contenu doit être orienté conversion Amazon

---

## 2. STRUCTURE DES ARTICLES

Chaque nouvel article doit contenir :

- Titre SEO (H1)
- Meta description
- Introduction (problème + solution)
- Verdict rapide (Top produits)
- Tableau comparatif
- Guide d’achat
- Section TEST produit détaillée
- FAQ SEO
- Conclusion

---

## 3. SECTION TEST PRODUIT

Chaque produit doit inclure :

- Présentation
- Analyse détaillée
- Qualité de fabrication
- Utilisation quotidienne
- Performances
- Entretien
- Avantages
- Inconvénients
- Public cible (animal ou utilisateur)
- Note (/10)
- Bouton Amazon

---

## 4. PRODUITS & IMAGES

- Les produits doivent venir de products.ts
- Aucun lien Amazon ne doit être écrit directement dans les articles
- Chaque produit doit avoir :
  - nom exact
  - image exacte correspondant au produit
  - lien affilié

- Les images doivent être strictement liées au produit référencé
- Les images doivent provenir uniquement d’Amazon ou de sources officielles du produit
- Interdit : images génériques
- Interdit : images IA
- Interdit : images non correspondantes
- Les images ne doivent jamais modifier le design du site
- Les images doivent uniquement être affichées dans les composants ProductCard

---

## 5. COMPARATIF

Inclure un tableau comparatif avec :
- prix (ou “voir sur Amazon”)
- note
- caractéristiques principales
- avantages

---

## 6. SEO

- Meta title dynamique
- Meta description dynamique
- OpenGraph
- Schema.org (Article + FAQ + Product)
- URLs propres
- Maillage interne entre articles

---

## 7. PERFORMANCE

- Utiliser next/image pour toutes les images
- Optimiser Core Web Vitals
- Site rapide mobile-first

---

## 8. OBJECTIF FINAL

Chaque article doit :
- être utile pour l’utilisateur
- être optimisé Google SEO
- convertir en ventes Amazon
- être meilleur que les concurrents

---

Ce fichier doit être bien structuré en Markdown et servir de guide permanent pour tous les agents IA du projet.
